# Unofficial Deployment Methods

This page collects community-maintained, third-party deployment methods.

All kinds of third-party deployment methods are welcome! If you have a reusable deployment approach, feel free to open a PR to the CdsCTF documentation repository and add it to this page.

> [!WARNING] Disclaimer
> The CdsCTF official team is not responsible for any potential issues caused by unofficial deployment methods.
