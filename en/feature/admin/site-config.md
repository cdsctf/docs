# Site configuration

The following are configured in the **admin panel** and stored in the database (not in `config.toml`). Configure them in the admin UI after deployment.

## Captcha

Supports hCaptcha, Cloudflare Turnstile, or built-in image/POW captcha, plus difficulty and related options.

## Email

Configure SMTP and templates for verification, password reset, and similar flows.

## Site logo

Logo image used on the frontend. Upload or change it in the admin panel.
