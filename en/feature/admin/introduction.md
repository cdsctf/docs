# Admin Panel

The admin panel is used for day-to-day operations: managing challenges, contests, and site-wide configuration. After deployment, log in with an admin account to access it.

This section describes how to perform common tasks in the admin panel:

- **[Site configuration](./site-config)**: Captcha, email, logo, etc. (configured in the panel and stored in the database)
